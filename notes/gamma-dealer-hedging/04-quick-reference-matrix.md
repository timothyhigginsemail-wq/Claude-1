# Quick Reference Matrix

| Dealer Position | Option Type | Starting Delta | Initial Futures Hedge | Gamma State | Dealer Futures Action on Moves |
|---|---|---|---|---|---|
| Long (Bought) | Call | Positive (+) | Sell Futures | Long Gamma (+) | Sell Rallies / Buy Dips (Stabilizing) |
| Long (Bought) | Put | Negative (-) | Buy Futures | Long Gamma (+) | Sell Rallies / Buy Dips (Stabilizing) |
| Short (Sold) | Call | Negative (-) | Buy Futures | Short Gamma (-) | Buy Rallies / Sell Dips (Accelerating) |
| Short (Sold) | Put | Positive (+) | Sell Futures | Short Gamma (-) | Buy Rallies / Sell Dips (Accelerating) |
